# 메트릭 블룸 · Metric Bloom (GPT-6 Pro 비교판)

이 폴더는 별도 비교를 위해 함께 공개한 프로젝트 사본입니다. [두 버전 비교 페이지](https://legerdo.github.io/metric-bloom-opus-5-5/comparison/)에서 플레이할 수 있습니다. 독립 실행 주소는 `https://legerdo.github.io/metric-bloom-opus-5-5/comparison/gpt6-pro/`입니다. 배포 파일은 루트 게임과 별도로 빌드됩니다. 두 버전은 서로 다른 LocalStorage 저장 키를 사용해 같은 브라우저에서도 진행이 서로 덮어쓰이지 않습니다.

작은 창작자의 작업실이 연결된 옥상 마을로 성장하는 한국어 픽셀아트 인크리멘탈 게임입니다. 직접 발행하던 일을 작업대, 공동 제작, 연결망과 자동화에 맡기고, 마지막에는 서로 다른 세 방송을 완성해 **빛의 개화제**를 엽니다.

## 실행

Windows에서 **`Start-Game.cmd`를 더블클릭**하거나 다음 명령을 실행합니다.

```powershell
cd comparison\gpt6-pro
npm ci
npm run dev
```

브라우저 주소: `http://127.0.0.1:4177` (로컬에서 루트 폴더로 실행할 때)

Node.js 24 환경에서 검증했습니다. 첫 설치 이후 게임 실행에는 외부 API, CDN, 로그인, 데이터베이스 또는 이미지 생성 서비스가 필요하지 않습니다. 모든 그래픽은 프로젝트의 픽셀 드로잉 코드로, 음악과 효과음은 Web Audio로 구성됩니다.

## 첫 플레이

`창가에 불 켜기`로 시작한 뒤 이야기를 네 번 발행하면 관심 16을 얻습니다. 작은 작업대를 마련하면 곧바로 자동 생산이 시작됩니다. 이후에는 설비와 연구에 투자할 몫, 다음 계획에 기여할 몫을 나눕니다. 현재 병목과 가까운 생산 돌파 목표는 게임 안에 표시됩니다.

마우스와 터치로 모든 메뉴를 조작할 수 있습니다. `Space`는 발행/라이브, `1`~`4`는 관리 탭, `Esc`는 창 닫기입니다. 음악과 효과음은 설정에서 독립적으로 조절하고 움직임을 줄일 수 있습니다.

## 진행 구조

* **발행 → 제작 → 대화 → 기록:** 관심, 연결, 기록이 순차적으로 열립니다. 생산이 다음 생산의 기반이 되며, 소비한 기록도 누적 기록 배율에 남습니다.
* **연결망 설계:** 6개 모듈을 배치합니다. 서로 다른 이웃 관계가 각각 관심·연결·기록을 증폭합니다. 이미 만든 모듈의 재배치는 무료입니다.
* **미래 선택:** 한 번의 새 계절 전환으로 더 큰 영구 배율을 얻거나, 현재 설비를 유지하는 연속 제작 협약을 택할 수 있습니다. 확인 창을 거치며 두 선택은 상호 배타적입니다.
* **관리의 자동화 → 개화제:** 구매 우선순위와 예산 유보, 예약 라이브, 이벤트 큐레이터를 운영합니다. 마지막에는 각 방송에 맞는 연결망과 제작 배분이 필요합니다. 엔딩·플레이 통계·크레딧을 보고 완성된 마을을 계속 둘러볼 수 있습니다.

일반 첫 플레이는 90~150분을 목표로 합니다. 실제 사람의 전체 플레이 시간을 측정한 결과가 아니라, 서로 다른 구매 간격·제작 배분·시즌 선택을 사용하는 결정적 시뮬레이션으로 경제 도달성을 검증합니다. 상세 수치는 `evidence/balance.json`과 `docs/VALIDATION.md`에 기록합니다.

## 저장

15초마다 브라우저 LocalStorage에 자동 저장합니다. 저장 버전, 입력 검증, 백업 복구, 내보내기/가져오기, 확인 후 새 게임을 지원합니다. 동시에 연 두 탭이 서로의 진행을 덮어쓰지 않도록 보호합니다.

오프라인 보상은 **최대 30분, 50% 효율**입니다. 거대한 프레임 지연을 그대로 적용하지 않으며, 복귀 시 경과 시간으로 별도 계산합니다. 놓친 이벤트는 손실을 만들지 않습니다.

저장은 브라우저와 주소에 귀속됩니다. 개발 주소 `4177`과 빌드 미리보기 `4178`은 서로 다른 저장 공간입니다. 옮길 때는 설정의 내보내기/가져오기를 사용하세요.

## 빌드 및 검증

```powershell
npm run check       # 경제 테스트 + TypeScript 검사 + 배포 빌드 + 전체 진행 시뮬레이션
npm run test:e2e    # dist를 실제 Chrome에서 실행하는 브라우저 테스트
npm run preview     # 빌드 결과: http://127.0.0.1:4178
```

브라우저 테스트는 로컬 Chrome을 사용하며, 외부 네트워크 요청을 차단한 상태에서 수행합니다. `npm run check`를 먼저 실행해야 최신 빌드와 정상 진행에서 얻은 중후반 테스트 저장이 생성됩니다. 테스트는 독립된 브라우저 컨텍스트를 사용하므로 평소 브라우저의 게임 저장을 변경하지 않습니다.

`dist/`는 정적 배포 파일입니다. 로컬 파일을 직접 더블클릭하는 대신 HTTP 정적 서버로 제공합니다. 이 프로젝트의 공개 빌드는 상위 저장소에서 `npm run build:pages`로 생성하며 `docs/comparison/gpt6-pro/`에 배치합니다.

## 코드 경계

| 경로 | 역할 |
| --- | --- |
| `src/game/content.ts` | 자원, 설비, 연구, 계획, 이벤트, 최종 방송의 공통 정의 |
| `src/game/economy.ts` | 렌더러와 분리된 생산·구매·배분·해금·자동화·시즌·엔딩 |
| `src/game/save.ts` | 저장 검증, 백업과 복구 |
| `src/view/` | 성장하는 마을, 픽셀 드로잉, 캐릭터 애니메이션과 피드백 |
| `src/ui.ts`, `src/main.ts` | 한국어 UI와 실제 입력/저장/시간 진행 연결 |
| `src/audio.ts` | 자체 음악과 효과음 |
| `scripts/balance.ts` | 치트 자원 없이 새 게임부터 엔딩까지 진행하는 전략 시뮬레이션 |
| `tests/` | 경제 회귀 테스트와 실제 브라우저 흐름 검증 |

개발용 디버그 진입점은 개발 모드에서 명시적으로 켰을 때만 존재합니다. 배포 빌드의 일반 플레이에는 노출되지 않습니다. 게임 규칙은 특정 AI 모델이나 개발 도구에 의존하지 않습니다.
