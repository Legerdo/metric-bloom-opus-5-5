- `npm run build:pages`가 두 프로젝트를 각각 빌드하고 한 번에 `docs/`에 반영합니다. 어느 한쪽의 빌드가 실패하면 기존 Pages 파일을 유지합니다.

## 게임 플레이와 스토리

- 예약 게시와 자동 운영이 쌓은 페르소나, 추천에서 보이지 않던 민트초코의 안부, 계정의 목소리를 정하는 선택까지 세 사건을 추가했습니다.
- 사건은 루틴과 팔로워가 성장한 뒤 순서대로 도착합니다. 게임을 실제로 플레이하는 시간에 맞춰 열리고, 대화 창을 닫아도 답을 고를 때까지 기다립니다. 메시지 기록에서 완료한 이야기를 다시 볼 수 있습니다.
- 선택은 자원 보상, 생산 방식, 엔딩 문장에 반영됩니다. 마지막에는 직접 목소리로 말하기, 에코와 함께 운영하기, 에코에게 별도 무대를 주기 중 하나를 고릅니다.
- 답장, 게시, 사건 등장에 맞춰 픽셀 연출·효과음·연속 대화 표시를 추가했습니다. 화면 효과 줄이기 설정과 운영체제의 모션 감소 설정을 반영합니다.

## UI와 접근성

- 목표, 트렌드, 게시 버튼이 게임 화면을 덮지 않도록 실제 배치 공간을 확보했습니다.
- 모바일·좁은 창에서 HUD, 운영 탭, 모달, 엔딩이 화면 밖으로 밀려나는 문제를 줄였습니다. 탭 메뉴에는 가로 이동 버튼과 키보드 방향 탐색을 추가했습니다.
- 목표 문장, 대사, 댓글과 보상 문구가 작은 화면에서 잘리지 않도록 줄바꿈과 위치를 조정했습니다.
- 이야기를 읽거나 선택할 때 게임 시간을 멈추고 키보드 초점을 대화 창 안에 유지합니다. 엔딩은 한 번에 펼쳐 읽을 수 있습니다.

## 저장 데이터와 배포

- 기존 저장에 이야기 진행 상태가 없는 경우 기본값을 채우므로 이어서 플레이할 수 있습니다. 진행 중인 사건과 선택한 운영 방식도 저장·복원합니다.
- 원래 원샷 프롬프트를 수정하지 않고 프로젝트 루트에 보존했습니다. 이 문서는 이후 추가한 게임플레이, 화면, 이야기 변경을 따로 기록합니다.
- Vite 경로 설정을 유지하고 `main/docs` 방식으로 Pages를 배포할 수 있도록 정적 사이트 복사 명령을 추가했습니다.

## 검증

- TypeScript 검사와 Vite 프로덕션 빌드를 통과했습니다.
- 단위 테스트 37개를 통과했습니다.
- 게시·구매, 세 에피소드와 운영 분기, 저장·복원, 실제 엔딩을 브라우저에서 확인했습니다. 후반 화면과 UI는 가로·세로를 포함한 8개 해상도에서 확인했습니다.
- 후반 브라우저 검증은 정상 경제 시뮬레이션으로 진행한 저장을 불러오는 방식입니다. 모바일 기기 실물과 재부팅 후 지속성은 별도로 시험하지 않았습니다.
